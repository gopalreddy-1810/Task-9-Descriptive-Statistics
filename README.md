#  Task 9 – Descriptive Statistics 

##  Project Overview

This project is part of **Task 9 – Descriptive Statistics Primer**.  
The objective is to analyze the **Iris dataset** using descriptive statistical methods in **Excel and Python (Pandas)**.

The analysis focuses on understanding the central tendency and spread of numerical variables.

##  Objectives

- Calculate Mean, Median, and Mode
- Calculate Standard Deviation
- Calculate 25th, 50th, and 75th Percentiles
- Understand the distribution and spread of the data
- Perform the same analysis using Excel and Python

## Dataset

The **Iris dataset** contains 150 flower observations with the following numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

##  Tools & Technologies

- Microsoft Excel
- Python
- Pandas
- Google Colab

##  Statistical Measures

The following descriptive statistics were calculated:

| Statistical Measure | Description |
|---|---|
| Mean | Average value of the data |
| Median | Middle value of the data |
| Mode | Most frequently occurring value |
| Standard Deviation | Measures the spread of data |
| 25th Percentile | Value below which 25% of observations fall |
| 50th Percentile | Median of the data |
| 75th Percentile | Value below which 75% of observations fall |

## Analysis & Findings

- Mean and median help describe the central tendency of the Iris measurements.
- Mode represents the most frequently occurring value in each numerical column.
- Standard deviation shows how much the values vary from the mean.
- The 25th, 50th, and 75th percentiles help understand the distribution of the data.
- Overall, the descriptive statistics provide a clear summary of the center and spread of the four Iris measurements.



##  Summary Statistics

The project includes a summary statistics table containing the calculated Mean, Median, Mode, Standard Deviation, and Percentiles for all four numerical variables.

##  Conclusion

Descriptive statistics were successfully calculated using both **Excel and Python Pandas**. The analysis provides an understanding of the central tendency, variability, and distribution of the Iris dataset.
